# Contributing

Thanks for taking an interest in Eden.

The project is currently in early development. The initial
architecture and core functionality are still being established.

## Getting involved

For now, feedback on the project direction, proposed features
and technical approaches is welcome through GitHub Issues.

Larger changes should be discussed before implementation to
avoid duplicated work or changes that conflict with the
application's intended architecture.

## Development principles

Contributions should:

- Have a clearly defined purpose.
- Follow the existing architecture and coding conventions.
- Include appropriate automated tests.
- Update relevant documentation.
- Avoid unnecessary dependencies.
- Respect user privacy and security.
- Avoid introducing mandatory paid services.

## Commit messages

The project uses Conventional Commits.

Examples:

    feat(memory): add semantic note retrieval
    fix(models): handle inference timeouts
    docs: update installation instructions
    test(core): cover conversation persistence

Commits should describe a single logical change where possible.

## Pull requests

Pull requests should explain:

- What has changed.
- Why the change is needed.
- How the change has been tested.
- Any known limitations.
- Any relevant security or compatibility concerns.

## Development environment

Setup instructions will be published alongside the first
installable version of Eden.
