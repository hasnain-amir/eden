# Eden branding

Intelligence that grows with you.

Eden uses a dark glass design with violet, lavender and blue
accents. The design system is called Violet Glass.

## Usage

The glass symbol is the main visual identity of Eden.

The flat symbol is a simplified vector interpretation intended
for smaller interface elements.

The product name is Eden. The visual wordmark uses lowercase
lettering followed by a full stop.

Do not stretch the logos, alter their proportions or introduce
unnecessary effects.

Larger raster assets have been resampled from the original
artwork. They are not native high-resolution renders.
