# Security policy

Eden is designed to work with personal information and local
application data. Security and privacy are important parts of
the project's development.

## Supported versions

There are no stable application releases at present.

Supported versions will be documented once the first installable
release is available.

## Reporting a vulnerability

Please do not report sensitive security vulnerabilities through
public GitHub issues.

Use GitHub private vulnerability reporting when it is available
for this repository.

Include as much relevant information as possible, such as:

- A description of the vulnerability.
- The affected version or component.
- Steps to reproduce the issue.
- The potential impact.
- Any suggested fixes or mitigations.

Do not include real credentials, private user information or
unnecessary personal data.

## Security principles

Eden aims to:

- Keep private information local wherever possible.
- Enforce permissions independently of AI models.
- Require appropriate authorisation for sensitive actions.
- Protect credentials and application data.
- Treat external content as untrusted.
- Maintain an auditable record of consequential actions.

These principles describe the intended architecture. They do
not imply that all security controls have been implemented.
