# Product vision

## Why I'm building Eden

I want to build a personal AI assistant that becomes more
useful the longer I use it.

Most AI assistants are useful for answering questions, but
their ability to manage knowledge, carry out independent work
and adapt to individual workflows can be limited.

Eden is my attempt to explore how local AI models, persistent
memory, software integrations and controlled automation can
work together within one application.

## Long-term objectives

The aim is for Eden to support education, business, research,
creative work, programming and personal organisation.

Its capabilities should develop gradually through new tools,
feedback, research and improvements to the application.

## Local-first operation

I want the core application to work without mandatory paid
services.

Personal information should remain under the user's control,
and the application should be able to operate independently
of any particular AI model provider.

## Learning and memory

Eden should maintain knowledge independently of the language
models it uses.

This will allow it to retain useful information, previous
decisions and feedback when its underlying models change.

Obsidian is the planned foundation for its human-readable
knowledge base.

## Autonomy

Eden should be able to perform independent work within limits
set by the user.

Users should be able to decide which activities are allowed,
which require approval and which are restricted.

## Extensibility

I want other developers to be able to understand the
application and introduce new capabilities without needing
to rewrite its core systems.

The project will therefore prioritise clear interfaces,
documentation, testing and maintainable code.

## Current status

Eden is in early development. The functionality described in
this document represents the intended direction of the project.
